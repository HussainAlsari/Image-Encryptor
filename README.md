# Image-Encryptor
Image Encryptor
Minimalist Image Encryptor
https://hussainalsari.github.io/Image-Encryptor/
A simple, client-side web application to encrypt and decrypt images using a password. Everything runs locally in your browser, no data is sent to any server.

Features

Encrypt any image with a password.

Automatically generate a strong password.

Decrypt .enc files using the correct password.

Fully client-side: no server upload.

Minimalist and responsive design.


How to Use

Encrypt Image

1. Open index.html in your browser.


2. Select an image to encrypt.


3. Enter a password, or leave empty to auto-generate.


4. Click Encrypt & Download.


5. Copy the generated password and share it securely with the recipient.



Decrypt Image

1. Open index.html in your browser.


2. Select a .enc file.


3. Enter the password.


4. Click Decrypt & Download to get the original image.



Security Note

All encryption happens in the browser (client-side).

Passwords must be shared securely with the recipient.

The app uses AES-GCM and PBKDF2 for strong encryption.


Installation

No installation required. Just open index.html in a modern browser.
